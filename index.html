    首次使用設定

    1. Spotify Client ID

    在 Spotify Developer Dashboard 建立 App，將 Redirect URI 設為：

    http://127.0.0.1:8876/callback

    開發者需有 Premium；請把登入帳號加入 App 的測試使用者。新 App 僅能讀取自己擁有或共同編輯的歌單。

    先在 Spotify Developer Dashboard 建立 App，再將 Client ID 貼到這裡。

    2. YouTube Music 登入設定

    在 Chrome 登入 YouTube Music，按 ⌘⌥I 打開開發者工具，切到 Network 並篩選 browse，再點 YouTube Music 的「音樂庫」。

    右鍵點 browse 請求 → Copy → Copy as fetch (Node.js)。回到專案資料夾，雙擊：

    連接YouTubeMusic.command

    設定程式會讀取剪貼簿、驗證登入並保存到本機。顯示成功後重新整理此頁。請勿把複製的內容貼到聊天或分享給他人。

    查看設定教學 ↗ · 完成後重新整理此頁。

    使用非 Google 官方的 ytmusicapi；服務變更時可能需更新套件或重新登入。
