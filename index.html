    連接 YouTube Music

    1. 用 Chrome 或 Brave 開啟 music.youtube.com 並登入，按 ⌘⌥I（Windows 按 F12）打開開發者工具，切到 Network 分頁。
    2. 重新整理頁面，在清單裡右鍵點任何一個 music.youtube.com 的請求 → Copy → Copy as cURL。
    3. 貼到下方欄位，按「驗證並儲存」。內容只會送到你電腦上的 Songferry，不會離開本機。

    也可以用 Copy as fetch (Node.js)，或 Firefox 的 Copy Request Headers。
    首次使用設定

    1. Spotify Client ID

    在 Spotify Developer Dashboard 建立 App，將 Redirect URI 設為：

    http://127.0.0.1:8876/callback

    開發者需有 Premium；請把登入帳號加入 App 的測試使用者。新 App 僅能讀取自己擁有或共同編輯的歌單。

    先在 Spotify Developer Dashboard 建立 App，再將 Client ID 貼到這裡。

    2. YouTube Music 登入設定

    按上方 YouTube Music 卡片的「連接 YouTube Music」，照面板裡的三個步驟，從瀏覽器複製一次已登入的請求貼上，Songferry 會在本機驗證並保存。不需要 Google API 金鑰。

    複製的內容含有你的登入 Cookie，只能貼進本機的 Songferry，請勿貼到聊天或分享給他人。進階用法（終端機指令、連接YouTubeMusic.command）見 README。
